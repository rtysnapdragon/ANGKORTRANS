គម្រោងបង្កើតប្រព័ន្ធគ្រប់គ្រង និងកត់ត្រា កម្មវិធីមង្គលការ និងកម្មវិធីផ្សេងៗទៀត
១. ម្ចាស់ក្រុមហ៊ុននៃប្រព័ន្ធ
២. ម្ចាស់កម្មវិធី
	២.១. ចុះឈ្មោះចូលប្រព័ន្ធ(ចុះខ្លួឯង ឬដោយAdmin រួច Admin អាច Assign Roles&Permission)
	២.២. ចូលរួចនឹងឃើញមានប្រព័ន្ធគ្រប់គ្រង និងអាច Setup កម្មវិធីរបស់ខ្លួនឯង
	២.៣. មាន Template ស្រាប់សម្រាប់រៀបចំធៀបការ Digital (ធៀបមានភ្ជាប់ QR code ឬកូដភ្ញៀវ) 
	២.​៤. បង្កើតបញ្ជីភ្ញៀវ​ដែលត្រូវអញ្ជើញចូលរួមកម្មវីធី
		- អាចកំណត់ភ្ញៀវណាខាងស្រី ខាងណាស្រី
	២.៥. បញ្ជូនព័ត៌មានទៅកាន់ភ្ញៀវដោយស្វ័យវត្ដិតាម Telegram ឬ Email
		- បើតាម Private Telegram គឹត្រូវមានលេខភ្ញៀវ(ភ្ជាប់តេលេក្រាម) រួចបង្កើត Bot សម្រាប់ Generate លីងចូលឆាតរួចផ្ញើ
	២.៦. Generate Link នៃធៀប និងកម្មវីធី​ រួចបញ្ជូនទៅកាន់ភ្ញៀវ
		- ភ្ញៀវចូលតាមលីងបានដោយ Public page
	២.៧. កត់ត្រាចំណងដៃ
		- ពេលបញ្ចូលលុយនៃភ្ញៀវដែលចូលរួម អាចត្រូវកំណត់ម្ដងទៀតពីភ្ញៀវខាងស្រី ឬប្រុស
		+ ករណីស្រប
			-​ ម្ចាស់កម្មវីធីកត់ត្រា ឬអ្នកផ្សេង ចូលប្រព័ន្ធ
			- អាចស្កេន QR code តាមទូរស័ព្ទ ឬម៉ាស៊ីនស្កេន ទៅលើធៀបការដែលភ្ញៀវបង្ហាញ
		+ ករណីសម្រួល
			- ភ្ញៀវមិនយកធៀបមក អ្នកកត់ចំណងដៃត្រូវស្វែងរកតាមឈ្មោះក្នុងប្រព័ន្ធបើឃើញត្រូវកែដើម្បីបញ្ចូលតម្លៃចូលរួមចងដៃ
			- ភ្ញៀវមិនបានអញ្ជើញ ត្រូវកត់ត្រាឈ្មោះថ្មី ខាងស្រី ឬប្រុស
			- អាចកត់ចំណងដៃលចូលប្រព័ន្ធបាន ក្រោយបញ្ចប់កម្មវីធី
	២.៨. អញ្ជើញភ្ញៀវចូលតុ អាចត្រូវ Update ចូលប្រព័ន្ធ ចូលតុណា(តុមិនសំខាន់ និងចាំបាច៉)
	២.៩. បញ្ជី និងរបាយការណ៍ លុយដែលដាក់បញ្ចូល(តាមប្រភេទនៃតម្រូវការ) និងចំណាយដែលកើតមានឡើងក្នុងកម្មវីធី
	២.១០. រូបថតបង្គលការត្រូវ Upload ចូលប្រព័ន្ធ(អាច Google Drive) រួចផ្ញើលីងឲ្យភ្ញៀវចូលយក
	២.១១. បិទបញ្ចប់កម្មវិធីចុងក្រោយត្រូវផ្ញើការថ្លែងអំណរអរគុណដល់ភ្ញៀវតាមរយៈ (Personal Telegram ឬ Email)
៣. ​​ដំណើរការនៃប្រព័ន្ធទាំងមូល
	៣.‌១.​ ម្ចាស់កម្មវិធីទាក់ទងចុះឈ្មោះ
		- ចុះឈ្មោះខ្លួនឯងតាម Website របស់ក្រុមហ៊ុន ឬក្រុមហ៊ុនចុះឈ្មោះឲ្យដោយផ្ទាល់
		-​ ប្រើ ឈ្មោះ(username) ឬEmail និង Password ដើម្បីចូលប្រព័ន្ធ
		-​ Admin ដាក់តួនាទី និងសិទ្ធដល់ម្ចាស់កម្មវិធី និងអាចបង្កើត Username ឲ្យផ្សេងទៀតដល់ម្នាស់កម្មវិធី
	៣.២. តួនាទី និងសិទ្ធិលើប្រព័ន្ធ
		- ម្នាស់កម្មវិធីជាំ Admin នៃប្រព័ន្ធដែលបានចុះឈ្មោះរួច
		- សិទ្ធីបង្កើត លុប កែ មើល សម្រាប់ Admin និងអ្នកប្រើប្រាស់ធម្មតា អាចមិនមានសិទ្ធិលុប និងកែ
		- Admin មានសិទ្ធីបញ្ចូលព័ត៌មានទៅកាន់ភ្ញៀវ
		- មើលរបាយការណ៍ និងទាញរបាយការណ៍
	៣.៣. បង្កើតលក្ខណៈពិសេស និងការបញ្ជូនព័ត៌មាន
		- ម្ចាស់កម្មវិធីយ​ក Token ពី Telegram bot (បើអាច) ដើម្បី Setup ឲ្យបញ្ជូនព័ត៌មានចូលក្រុម
		- ម្ចាស់កម្មវិធីយ​ក GroupId ដើម្បីដាក់ Setting Up ក្នងុប្រព័ន្ធ ដើម្បីបញ្ជូនព័ត៌មាន
		- ចូល OAuth2 Google បើអ្នកប្រើប្រាស់ចង់បានការទុកទិន្នន័យក្នុង Google Drive(Cloud)
៤. ការចូលប្រព័ន្ធ
